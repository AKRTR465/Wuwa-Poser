# Wuwa Poser · 鸣潮 MMD 播放器

让喜欢的角色在《鸣潮》里跳起来。加载 VMD 动作与表情，为演员安排站位，搭配镜头和音乐，在游戏场景中同步播放。播放 MMD 无需 Blender。

[下载 Windows 版](https://github.com/AKRTR465/Wuwa-Poser/releases) · [播放器指南](tools/MMD_PLAYER.md) · [构建说明](docs/BUILDING.md) · [问题反馈](https://github.com/AKRTR465/Wuwa-Poser/issues)

当前公开版本为 **v0.2.1 测试版**，面向 Windows x64。角色目录登记了 64 个配置、80 个角色与皮肤组合，另有 4 个独立形态选项；不同游戏版本、角色和动作的兼容性仍需逐项验证。

## 下载与运行

1. 在 [Releases](https://github.com/AKRTR465/Wuwa-Poser/releases/tag/v0.2.1) 下载 `Wuwa-Poser-v0.2.1-win-x64.zip`，完整解压到游戏目录之外的可写文件夹。
2. 双击 `WWPoser.exe` 或 `start.cmd`。便携包包含 .NET 运行库与录屏依赖，无需安装 Python、.NET 或 Blender。
3. 打开鸣潮，进入角色可见的场景，在平坦地面站定。
4. 在播放器按“演员与动作 → 站位与舞台 → 开始表演”完成设置，再点击开始。加载时按提示切回游戏，并确认系统弹出的权限请求。
5. 看完后点击 **停止并恢复**，等待演员退场、队员与镜头恢复，再关闭播放器。

建议使用 Windows 11 x64；Windows 10 22H2 x64 请自行确认系统与显卡驱动支持所需的窗口采集功能。当前只提供 x64 包。

原生模块需要 [Microsoft Visual C++ x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。若系统提示缺少 `VCRUNTIME140.dll` 或 `MSVCP140.dll`，请安装该运行库后重试。

打开播放器本身不会开始播放。请保留压缩包中的目录结构，不要只复制 EXE。动作、镜头、音乐及游戏文件需要自行准备。

## 开始使用

| 想做什么 | 操作 |
| --- | --- |
| 添加演员 | 在“演员与动作”添加人物，选择角色、皮肤或形态；同一角色及其不同形态可以分别添加多次 |
| 选择动作与表情 | 给各演员选择身体 VMD，可另选表情 VMD；支持拖入文件和共用第一人的动作 |
| 摆好队形 | 在 3D 站位舞台拖动演员、箭头或朝向圆环，也可输入坐标、套用一字／半圆／V 字队形 |
| 先看站位 | 点击“在游戏里预览站位”；无需动作文件，结束预览后可继续调整 |
| 还原动作原作队形 | 选择“原作队形”，使用 VMD 自带的位置关系，配合对应镜头 |
| 配合镜头与音乐 | 在“站位与舞台”选择跟随、固定或 VMD 镜头，添加本地配乐并设置偏移、音量 |
| 使用原生物理 | 默认启用游戏原生物理；具体效果取决于角色与动作 |
| 控制播放 | 在“开始表演”播放、暂停、逐帧、跳转；可调整速度、循环和自动结束时间 |
| 保存喜欢的时刻 | 使用节目书签，重新载入相同节目后跳回保存的时间 |
| 录制视频 | 播放前选择 30／60 FPS、1080p／2K／原尺寸；默认硬件编码，启动失败时有界回退；支持自动与手动录制 |
| 结束表演 | 点击“停止并恢复”；暂停和到达动作末帧仍会保留当前表演 |

播放器使用一个动态演员列表和共同时间轴。开始时优先借用当前编队中角色、皮肤和模型匹配的演员，其余演员独立创建；同一原演员只借用一次。停止时恢复借用队员，移除本次新建的演员。

多形态角色的默认与特殊形态均独立创建，可同时表演。当前选项和验证范围见 [独立角色形态](docs/CHARACTER_FORMS.md)。

“原作队形”播放会扣除主控胶囊与地面之间的行走间隙；无法读取有效间距时，默认向下补偿 2.5 cm。修正作用于动作与镜头高度，可叠加演员的手动高度设置。

主控角色的实际模型未参演时，播放与站位预览默认隐藏它；借用主控模型参演时保持可见。停止、关闭或启动失败时恢复隐藏前的显示状态。

界面没有固定人数上限，实际承载能力受游戏与机器资源限制。建议先从少量演员开始；目录收录与离线检查不代表所有组合都完成实机验证。

详细的舞台快捷键、站位坐标、镜头模式和物理说明见 [播放器指南](tools/MMD_PLAYER.md)。

## 配乐与录屏

配乐支持 FLAC、WAV 和 MP3，跟随共同时间轴暂停、跳转、循环、变速和调节音量。首次使用会自动准备并缓存配乐，无需手动转换格式。

录屏采集鸣潮窗口。最终视频的配乐由所选音乐与实际时间轴记录合成，**不包含游戏声、系统声或麦克风**。当前录屏效果仍需按具体系统环境验证。

录屏设置会显示实际保存路径，可点击“打开录屏文件夹”。工作区内的本地版本统一保存到工作区的 `playback/recordings/`；独立便携包保存在包内的同名目录。

## 更新与移除

先停止并恢复，关闭旧播放器，将新版本完整解压到新文件夹。若游戏已经加载过旧版角色模块，升级后需要重启一次游戏，再使用新播放器。

播放器不提供自动更新。个人动作、音乐、准备目录和录像请自行保留；删除文件夹前先备份需要的内容。使用结束后确认恢复完成，再移除便携包。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 提示找不到游戏或主窗口 | 确认只有一个鸣潮实例，已经进入角色场景；开始加载时按提示切回游戏 |
| 系统询问权限 | 游戏内加载通过临时安装器请求权限；取消后本次操作不会继续 |
| 动作结束了，演员还在 | 非循环播放会保持末帧；点击“停止并恢复”结束会话 |
| 正在恢复，暂时不能再开始 | 等待恢复完成；按界面提示重试停止，并保留本次会话记录用于反馈 |
| 音频设备或格式报错 | 检查音乐文件完整、输出设备可用，保留包内的音频工具目录；修正后可重新应用配乐 |
| 角色浮空或脚底穿地 | 调整站位高度；当前手动站位没有自动接地，斜坡与台阶需要自行处理 |
| 选择了表情却没有变化 | 表情依赖角色实际网格的 morph 映射，部分角色或独立脸部网格可能没有可用目标 |
| 镜头构图不合适 | 核对站位方式和镜头素材是否配套，并调整角色起点；本版包含舞台全局坐标与镜头局部坐标混用的修复 |
| 更新游戏后无法加载 | 游戏版本变化可能使运行契约失效；请提交版本、复现步骤和相关记录，等待适配 |

反馈时请注明播放器版本、游戏版本、角色／皮肤、操作步骤和报错。提交日志前移除个人路径等信息；不要上传无权分享的动作、音乐或游戏文件。

## 数据保存位置

以下路径相对于播放器文件夹；运行后按需生成。

| 内容 | 路径 |
| --- | --- |
| 已准备的动作与镜头 | `playback/actor_preparations/` |
| 播放会话与恢复记录 | 对应准备目录下的 `runtime_sessions/` |
| 游戏内站位预览记录 | `playback/stage_previews/` |
| 默认录像输出 | `playback/recordings/`，也可在界面选择目录 |
| 角色适配与目录数据 | `data/characters/` |

书签保存位置由文件对话框选择。运行时还会保留按游戏进程身份区分的会话占用记录，用于防止多个播放器重叠控制同一游戏。

## 从源码构建

需要 PowerShell 7、.NET 10 SDK、Visual Studio 2022 C++ Build Tools 与 Windows SDK，以及六个本地游戏参考 DLL。参考 DLL 不随源码和 Release 分发。

```powershell
git clone https://github.com/AKRTR465/Wuwa-Poser.git
cd Wuwa-Poser
pwsh -NoProfile -File tools/prepare_player_dependencies.ps1 -Download
pwsh -NoProfile -File tools/build_player.ps1 -Rebuild -PublicRelease -ReferenceDirectory 'D:\WuwaReferences'
```

成功后便携目录位于 `dist/`。参考 DLL 名称、编译器路径和离线检查方法见 [构建说明](docs/BUILDING.md)。
