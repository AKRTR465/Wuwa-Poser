# 鸣潮 MMD 播放器

## 动态演员列表

运行 `WWPoser.exe` 或 `start.cmd`，点击“添加演员”，从统一角色/皮肤目录选择人物。可重复添加同一角色，演员数量不固定为 1、3 或 16。界面按左侧三个步骤引导：“演员与动作”左边是演员列表，右边编辑选中演员的角色、身体/表情 VMD（可拖入文件）和折叠的初始站位；“站位与舞台”先选镜头，默认使用原作队形；选择“站位舞台”后才展开 3D 手动站位面板，再搭配配乐和物理；“开始表演”显示开始前检查清单与录屏设置，开始后出现时间轴和实时站位。

开始时，程序读取本次游戏的真实队伍，优先借用角色、皮肤和实际模型均匹配的原演员。每个原演员只分配给一个位置；未匹配及重复添加的其余演员独立创建。无需选择来源模式，也无需提供旧 stage 来源目录。

所有演员由一个加载器和播放宿主管理，使用一个时间轴和场景镜头。停止时恢复原队员、移除新建演员。窗口显示实际借用与新建数量。

表演开始后，点击时间轴下方的“从头播放”，即可从 0 秒重新开始。播放中、暂停时或动作播完后均可使用，动作、表情、VMD 镜头和配乐同步归零，保留演员站位、速度和循环设置，无需再次加载演员。自动结束仍按本次表演开始后的真实时间计时。

主控角色的实际模型未参演时，播放与站位预览默认隐藏它；如果借用了主控模型来跳舞，则保持可见。停止、关闭或启动失败时恢复原有显示状态，原本隐藏的模型仍保持隐藏。隐藏只改变模型显示，不改变主控的位置、碰撞或动画设置。

## 整场预设

侧栏的“保存预设”“加载预设”“另存为”保存整场表演，默认文件扩展名为 `.wwpreset`。保存会把原始身体动作、表情、镜头 VMD 和音乐一起打包，相同内容只存一份；移动原素材或升级播放器后，预设仍可恢复这些素材。

预设记录全部演员的数量、顺序、参与状态、角色/皮肤/形态、动作、表情、倍率、额外偏移、原地动作和舞台站位，并保存队形方式、间距、镜头模式与轨道、配乐偏移和音量、速度、循环、时限、物理、NPC 隐藏和自动录屏参数。重复角色及不同形态分别保留各自配置。已应用的实时演员偏移会写回演员配置，后续保存也会带上。

未选好动作的草稿也能保存；非空但已丢失的素材路径需重新选择或清空后再保存。加载会替换当前配置，有未保存的修改时先询问保存；需要先停止并恢复表演、结束站位预览和录屏。加载本身不会进入游戏或自动播放。缺失素材、当前版本不支持的角色或形态会明确提示，演员需要补全后才能开始。

素材缓存在 `%LOCALAPPDATA%\WuwaPoser\preset_cache`，与具体版本的程序目录分开。预设保存镜头模式与 VMD；当前游戏固定机位的具体位置、朝向暂不采集，也不保存游戏进程、运行时地址、编译缓存或时间轴书签。

## 播放时隐藏 NPC 和怪物

在“站位与舞台”勾选“播放时隐藏附近 NPC 和怪物模型”。播放开始时隐藏起点周围 100 米内、当前已加载的 NPC 和怪物，并在播放期间补充新加载的目标；保留演员、队员、其他玩家、动物及场景建筑。站位预览不会启用此选项。

停止、关闭或启动失败后恢复每个目标原来的隐藏状态。已经卸载或实体代次发生变化的目标不会继续修改；单个恢复失败会保留重试。此功能只隐藏模型，不暂停 AI，不取消碰撞，也不隐藏头顶 UI；隐藏的怪物仍可能攻击。游戏内实际效果尚待验证。

## 准备与开始

1. 添加所需演员，勾选参与者，为各人选择身体 VMD，可另选表情 VMD。
2. “共用第一人的动作”复制身体与表情素材路径，各演员仍按自己的骨架适配。
3. 在“站位舞台”里摆每位演员的起始位置：原点是开始播放那一刻你操控的角色，X 向其右、Y 向其前、Z 向上。点中演员后拖红 / 绿 / 蓝箭头只沿 X / Y / Z 移动，拖人在地面上移动，拖圆环改朝向；右键或中键拖动旋转视角，Shift + 右键平移，滚轮缩放；G 抓取（再按 X / Y / Z 锁轴）、R 旋转、Esc 取消，1 / 3 / 7 正视 / 侧视 / 顶视，5 切换正交，Home 框选全部。默认对齐 10 cm 和 15°，按住 Shift 自由移动。也可直接输入向右、向前、离地高度和朝向（0 与你同向，180 面向你），或用“一字排开 / 半圆 / V 字”一键队形。未指定的演员仍按演员数排列网格，可调整间距。指定位置写入 `actors.tsv` 的舞台坐标，只在开始播放时生效，不需要重新编译动作。站位舞台下方的“在游戏里预览站位”不需要身体动作：它按当前站位请所有参与演员上台，原地静止、不播放动作、表情、镜头或物理，方便对照场景；预览中的演员一律另行创建（不借用队伍原角色）。改了站位后点“按现在的站位重新预览”，看完点“结束预览”；开始播放、停止并恢复或关闭窗口也会先结束预览。预览会话位于 `playback/stage_previews/`。原地动作、倍率和动作坐标内的额外偏移在演员编辑区的折叠项中。
4. 可选择一个共用镜头 VMD、镜头方式、物理方式和配乐。
5. 点击“准备动作”进行离线编译，或直接“开始播放”。开始时切回游戏，等待全部演员加载及原生物理图准备完成后同步播放。

“载入已准备动作”优先读取准备目录内封存的素材。原始素材文件移动后仍可使用完整准备目录。演员、素材内容或倍率改变时自动重新准备；速度、循环、时限和站位等运行参数改变会复用编译结果。

准备目录同时记录动作、表情和镜头编译器的散列。升级后编译器发生变化，会使用封存的原始素材重新准备，让骨骼适配修正应用到旧节目；整场预设无需重新制作。

演员增删、角色更换和素材更换在下一次开始播放时应用，不会在当前回调执行期间改动演员集合。播放中可以准备下一场素材。开始下一场之前会停止并恢复当前场。

升级后，如果游戏仍加载着旧版角色模块，需要重启一次游戏以载入新版；同一版本的正常连续播放不要求每次重启。

开启自动录屏时，演员和镜头会先停在动作起点，等待录屏收到首帧后再一起开始。等待录屏期间不消耗自动结束时限。若录屏未能就绪，界面会显示原因，场景保持暂停；可检查录屏设置后重新开始，或点击“停止并恢复”退出。

## 时间轴与实时控制

播放、暂停、逐帧、跳转、速度、循环、自动结束及书签作用于共同时间轴。时间轴覆盖所有身体、表情和镜头中最长的轨道，较短身体动作停在自己的末帧。

- 速度为 0.1–4 倍，逐帧步长为 1/30 秒。
- 非循环动作结束后保持末帧，仍可跳转或重新播放。
- 自动结束默认 0（不限），非零值按开始后的实际时间计算，暂停也计时。
- “挪一挪站位”按演员编号调整左右、前后、高度、朝向及原地动作，不会把同角色的多个实例混为一个。
- 改变物理后端需要重新开始。切换到 VMD 镜头时，该镜头素材必须已加载进当前会话。

原地动作只移除水平根位移，保留垂直变化。手动站位主要改变骨骼呈现，不等于自动接地；舞台附近台阶、斜坡或水面高低差仍需手动处理。

## 表情、镜头和物理

表情按每个实例实际网格的 morph catalog 映射、播放并恢复，最多映射 64 个目标。某角色没有对应 morph 时，选择表情文件不代表一定有可见效果；独立 Face 网格仍受当前映射实现范围限制。

镜头提供跟随、固定、VMD 轨道，两种模式共用舞台原点（开始播放时操控角色所站位置与朝向）作为世界参考：跟随镜头跟踪全体演员的实时质心；VMD 轨道围绕舞台原点运镜，方向跟随舞台朝向，不再被单人站位或单人朝向带偏。整个场景只持有一套镜头控制。

演员摆放使用 D_ 全局坐标，镜头 POV 使用局部坐标。舞台原点与地面高度通过相对首演员 Mesh 的位移传给镜头，每帧按当前 Mesh 局部位置还原，避免混用坐标及世界原点重定位导致的远距离错位。

新窗口默认使用「原作队形」：忽略手动站位图，全员从舞台原点出发，由各自动作自带的队形偏移还原原作构图。镜头设置位于站位舞台上方；只有选择「站位舞台」后，才展开手动摆放面板。切换模式会保留已输入的站位，载入已保存的节目时沿用节目记录的方式。摆放方式在开始播放时确定，播放中不可切换。

两种摆放方式均默认整体下移 2 cm。“整体离地高度”始终显示在摆放方式下方，负数向下，可按角色与场景修改；播放中点击“应用整体高度”实时更新全员，镜头使用相同高度。它与每位演员的额外高度叠加，保存预设会保留所选数值；设置为 0 即取消整体下移。新版用这一明确设置替代原作队形旧有的自动胶囊间距补偿，避免重复下移。站位预览同样应用整体高度一次。

将镜头 VMD 拖入镜头文件框，或通过「选择文件」载入后，会自动切换为「VMD 镜头轨道」；也可再手动选择跟随或固定镜头。

默认游戏原生物理。关闭后采用直接骨姿，可启用已有骨链资料支持的衣物惯性增强；原生物理与增强互斥。演员加载与发布前完成注册，播放回调中不扩容演员存储。

## 配乐、录屏和书签

本地配乐支持 FLAC、WAV 和 MP3，可设置偏移、音量，并与时间轴同步暂停、跳转、循环和速度。首次使用会自动解码为统一的 PCM 音频，开始表演前先完成准备；转换结果按音乐内容缓存于 `%LOCALAPPDATA%\WuwaPoser\audio_cache`，重复使用无需再次转换。转换不会修改原音乐文件，也不改变录屏合成所用的原始音源。

录屏绑定鸣潮窗口，支持 30/60 FPS、1080p、2K（2560×1440）与原尺寸，尺寸和帧率可独立组合。2K 保持画面比例缩放到 2560×1440，非 16:9 窗口会留黑边；原尺寸取偶数像素以兼容视频编码。低分辨率窗口选择 2K 会放大画面，不会增加原有细节。录制不包含麦克风、系统声或游戏声；最终配乐由所选音乐和实际时间轴记录合成。

所有尺寸和帧率优先使用 GPU 直连：WGC 在 NVIDIA D3D11 设备上捕获及缩放窗口画面，显存中的 BGRA 帧直接交给 NVENC，不经过 CPU 回读、缩放或格式转换。这是 Windows 窗口纹理捕获，尚未实现游戏内部 swapchain/backbuffer 捕获。

默认“省空间（HEVC）”直接录制 HEVC，使用 P4 单遍、VBR CQ 25；保留低延迟参数，关闭前瞻、AQ 和 B 帧。可选“兼容（H.264）”保留原 H.264 QP 21 编码，适合不支持 HEVC 的播放器或剪辑工具。两者均为有损编码，实际体积和画质取决于画面，省空间模式不承诺固定压缩比例。省空间模式的启动回退顺序为 HEVC GPU 直连、H.264 GPU 直连、HEVC 兼容、H.264 兼容、x264 软件编码；兼容模式仅尝试 H.264 两种硬件路径及软件编码。兼容硬件路径允许捕获设备回读，再交给 NVENC；界面与 `result.json` 标明实际使用的编码路径。硬件编码仍有捕获、显存带宽及写盘开销，游戏 GPU 满载时仍可能影响帧率。

仅未录到画面的启动失败会重试；停止录屏、窗口关闭、录制中断或已产生画面后不会自动重录。最终 MP4 只复制视频并合成音轨，HEVC 使用 `hvc1` 标记。发布最终文件前扫描原始及最终视频的全部帧包，核对编码、尺寸、包数、音轨和时长。正常停止且校验、结果记录成功后，自动删除本次的中间视频、PCM 音频与音乐副本，保留 `capture.log`、`capture_attempts.json`、音频时间轴及 `result.json`；日志记录回收字节数。录制中断、合成失败或校验失败时保留恢复素材。不会清理历史录屏。

保存音轨时，普通进度观察合并为连续播放段，避免状态轮询抖动造成音乐反复跳切。暂停、跳转、换曲、偏移、音量及变速等实际变化保留为分段；只有前后控制状态一致且不足 250 ms 的短暂不确定读取可补接。变速使用 SoX 高质量重采样，仍采用随速度改变音调的方式。最终音轨编码为 AAC 192 kbps。正数音乐偏移相对于动作时间轴延后，录屏若从动作中途开始，不会额外在视频开头插入同等长度的静音。

第三步的“录屏设置”在开始播放前就默认展开，可提前选择帧率、尺寸和格式，整场预设保存这些选择；旧预设未指定格式时使用省空间模式。“开始播放时自动录屏”默认关闭；开启后，播放成功启动时自动按所选设置录制，非循环动作播完即自动停止录屏、合成配乐并保存 MP4，无需再点保存。保存后演员保持末帧，仍可点击“停止并恢复”退场。循环播放与暂停期间继续录屏；点击“停止并恢复”、关闭播放器或会话结束恢复时也会自动保存。启动失败不会开始录屏。手动录制按钮始终保留；已在手动录制时不会重复启动录屏，也不会因动作播完或停止表演而结束手动录制。录制或保存期间锁定帧率、尺寸和格式，停止后可修改。

录屏设置显示实际的绝对保存路径，可点“打开录屏文件夹”直接查看。源码工作区内的本地打包版（`dist/`）与 `desktop/WWPoser/publish/` 共用工作区的 `playback/recordings/`，更新本地版本不会分散视频。单独解压到工作区之外的便携包使用包内的 `playback/recordings/`。

书签保存全部参与演员与轨道的节目身份及共同时间位置；同角色重复实例也按演员编号区分。重新加载同一节目可继续使用书签，改换素材后会提示不匹配。

## 停止与恢复

停止先结束身体输入、表情和镜头，再等待原生观察器退出。借用队员恢复原位置、朝向、可见性、tick、active 和动画更新设置；新建演员从对应创建管理器移除。部分恢复失败会持续记录 pending 状态并保留恢复服务，不把未完成的恢复报告为成功。

当前实现不设固定演员人数上限，但实机承载能力仍需测试。增加人数会增加模型、动作数据和物理计算开销。构建、离线准备和合成内存测试不等于游戏视觉与容量验收。
