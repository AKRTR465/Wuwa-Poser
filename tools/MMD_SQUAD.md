# 编队角色在统一播放器中的使用

编队内外已经合并到同一个动态演员列表。添加角色时无需选择队伍模式；开始时按当前真实编队优先借用匹配角色，其余实例独立创建。

借用要求角色配置、皮肤和实际模型匹配。每个原演员只借用一次，因此同角色添加多次时，至多一个位置使用该原演员，其余创建独立实例。当前编队的物理人数不会限制整场演员数量。

停止时先恢复身体、表情、物理和镜头，再恢复借用队员的原始状态；程序不会调用创建管理器去销毁借用队员。新建演员则从自己的管理器条目中移除。借用期间保留相应 entity hold，实际恢复完成后释放。

不再需要旧 stage 来源目录。旧单人、队伍、队伍外三种播放入口已从新 GUI 移除；它们的共享控制和加载均进入同一个宿主。完整操作见 [播放器指南](MMD_PLAYER.md)，实现与离线证据见 [动态演员记录](../docs/dynamic_actor_player_20261023.md)。
