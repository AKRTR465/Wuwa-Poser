# 鸣潮 MMD 播放器

## 动态演员列表

运行 `WWPoser.exe` 或 `start.cmd`，点击“添加演员”，从统一角色/皮肤目录选择人物。可重复添加同一角色，演员数量不固定为 1、3 或 16。界面按左侧三个步骤引导：“演员与动作”左边是演员列表，右边编辑选中演员的角色、身体/表情 VMD（可拖入文件）和折叠的初始站位；“站位与舞台”有一个 Blender 式 3D 站位舞台，再选镜头、配乐和物理；“开始表演”显示开始前检查清单，开始后才出现时间轴、实时站位和录屏。

开始时，程序读取本次游戏的真实队伍，优先借用角色、皮肤和实际模型均匹配的原演员。每个原演员只分配给一个位置；未匹配及重复添加的其余演员独立创建。无需选择来源模式，也无需提供旧 stage 来源目录。

所有演员由一个加载器和播放宿主管理，使用一个时间轴和场景镜头。停止时恢复原队员、移除新建演员。窗口显示实际借用与新建数量。

主控角色的实际模型未参演时，播放与站位预览默认隐藏它；如果借用了主控模型来跳舞，则保持可见。停止、关闭或启动失败时恢复原有显示状态，原本隐藏的模型仍保持隐藏。隐藏只改变模型显示，不改变主控的位置、碰撞或动画设置。

## 准备与开始

1. 添加所需演员，勾选参与者，为各人选择身体 VMD，可另选表情 VMD。
2. “共用第一人的动作”复制身体与表情素材路径，各演员仍按自己的骨架适配。
3. 在“站位舞台”里摆每位演员的起始位置：原点是开始播放那一刻你操控的角色，X 向其右、Y 向其前、Z 向上。点中演员后拖红 / 绿 / 蓝箭头只沿 X / Y / Z 移动，拖人在地面上移动，拖圆环改朝向；右键或中键拖动旋转视角，Shift + 右键平移，滚轮缩放；G 抓取（再按 X / Y / Z 锁轴）、R 旋转、Esc 取消，1 / 3 / 7 正视 / 侧视 / 顶视，5 切换正交，Home 框选全部。默认对齐 10 cm 和 15°，按住 Shift 自由移动。也可直接输入向右、向前、离地高度和朝向（0 与你同向，180 面向你），或用“一字排开 / 半圆 / V 字”一键队形。未指定的演员仍按演员数排列网格，可调整间距。指定位置写入 `actors.tsv` 的舞台坐标，只在开始播放时生效，不需要重新编译动作。站位舞台下方的“在游戏里预览站位”不需要身体动作：它按当前站位请所有参与演员上台，原地静止、不播放动作、表情、镜头或物理，方便对照场景；预览中的演员一律另行创建（不借用队伍原角色）。改了站位后点“按现在的站位重新预览”，看完点“结束预览”；开始播放、停止并恢复或关闭窗口也会先结束预览。预览会话位于 `playback/stage_previews/`。原地动作、倍率和动作坐标内的额外偏移在演员编辑区的折叠项中。
4. 可选择一个共用镜头 VMD、镜头方式、物理方式和配乐。
5. 点击“准备动作”进行离线编译，或直接“开始播放”。开始时切回游戏，等待全部演员加载及原生物理图准备完成后同步播放。

“载入已准备动作”优先读取准备目录内封存的素材。原始素材文件移动后仍可使用完整准备目录。演员、素材内容或倍率改变时自动重新准备；速度、循环、时限和站位等运行参数改变会复用编译结果。

演员增删、角色更换和素材更换在下一次开始播放时应用，不会在当前回调执行期间改动演员集合。播放中可以准备下一场素材。开始下一场之前会停止并恢复当前场。

升级后，如果游戏仍加载着旧版角色模块，需要重启一次游戏以载入新版；同一版本的正常连续播放不要求每次重启。

## 时间轴与实时控制

播放、暂停、逐帧、跳转、速度、循环、自动结束及书签作用于共同时间轴。时间轴覆盖所有身体、表情和镜头中最长的轨道，较短身体动作停在自己的末帧。

- 速度为 0.1–4 倍，逐帧步长为 1/30 秒。
- 非循环动作结束后保持末帧，仍可跳转或重新播放。
- 自动结束默认 0（不限），非零值按开始后的实际时间计算，暂停也计时。
- “挪一挪站位”按演员编号调整左右、前后、高度、朝向及原地动作，不会把同角色的多个实例混为一个。
- 改变物理后端需要重新开始。切换到 VMD 镜头时，该镜头素材必须已加载进当前会话。

原地动作只移除水平根位移，保留垂直变化。手动站位主要改变骨骼呈现，不等于自动接地；舞台附近台阶、斜坡或水面高低差仍需手动处理。

## 表情、镜头和物理

表情按每个实例实际网格的 morph catalog 映射、播放并恢复，最多映射 64 个目标。某角色没有对应 morph 时，选择表情文件不代表一定有可见效果；独立 Face 网格仍受当前映射实现范围限制。

镜头提供跟随、固定、VMD 轨道，两种模式共用舞台原点（开始播放时操控角色所站位置与朝向）作为世界参考：跟随镜头跟踪全体演员的实时质心；VMD 轨道围绕舞台原点运镜，方向跟随舞台朝向，不再被单人站位或单人朝向带偏。整个场景只持有一套镜头控制。

演员摆放使用 D_ 全局坐标，镜头 POV 使用局部坐标。舞台原点与地面高度通过相对首演员 Mesh 的位移传给镜头，每帧按当前 Mesh 局部位置还原，避免混用坐标及世界原点重定位导致的远距离错位。

摆放方式可切换：「站位舞台」按站位图各自站位（默认）；「原作队形」忽略站位图，全员站上舞台原点，由各自动作自带的队形偏移还原原作构图，配合 VMD 镜头轨道可复刻原作运镜。摆放方式在开始播放时确定，播放中不可切换。

默认游戏原生物理。关闭后采用直接骨姿，可启用已有骨链资料支持的衣物惯性增强；原生物理与增强互斥。演员加载与发布前完成注册，播放回调中不扩容演员存储。

## 配乐、录屏和书签

本地配乐支持偏移、音量，并与时间轴同步暂停、跳转、循环和速度。格式支持取决于本机 Windows MCI 解码器。

录屏绑定鸣潮窗口，支持 30/60 FPS、1080p/原尺寸。录制不包含麦克风、系统声或游戏声；最终配乐由所选音乐和实际时间轴记录合成。

书签保存全部参与演员与轨道的节目身份及共同时间位置；同角色重复实例也按演员编号区分。重新加载同一节目可继续使用书签，改换素材后会提示不匹配。

## 停止与恢复

停止先结束身体输入、表情和镜头，再等待原生观察器退出。借用队员恢复原位置、朝向、可见性、tick、active 和动画更新设置；新建演员从对应创建管理器移除。部分恢复失败会持续记录 pending 状态并保留恢复服务，不把未完成的恢复报告为成功。

当前实现不设固定演员人数上限，但实机承载能力仍需测试。增加人数会增加模型、动作数据和物理计算开销。构建、离线准备和合成内存测试不等于游戏视觉与容量验收。
